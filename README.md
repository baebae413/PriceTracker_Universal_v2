# PriceTracker — универсальный прототип

Android-трекер цен без собственного сервера.

## Что умеет
- добавлять URL конкретного товара;
- загружать реальную страницу товара через Android WebView;
- искать название и цену в JSON-LD, DOM, meta/тексте страницы;
- повторно проверять сохранённые товары;
- показывать ↓ / ↑ / =;
- локально хранить товары в SQLite.

В приоритете тестируются Ozon, Яндекс Маркет и Подружка. Универсальный режим не может гарантировать поддержку абсолютно любого сайта: магазины могут использовать CAPTCHA, авторизацию, антибот-защиту или нестандартную загрузку цены.

## Сборка
GitHub Actions запускает `gradle assembleDebug` и публикует `price-tracker-debug`.
